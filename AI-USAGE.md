\# NEXORA 2026 – AI Usage



AI tools were used as a development assistant during this project.



\## How AI was used



AI assistance was used for:



\- Understanding the challenge requirements.

\- Planning the project structure.

\- Drafting API code and automated tests.

\- Improving documentation and README content.

\- Identifying possible edge cases and error-handling requirements.



\## Human Verification



The generated code was run locally and tested using the provided validation script and API tests.



The final implementation was reviewed and adjusted before submission.



\## One Thing AI Got Wrong



AI initially suggested running the baseline commands from the `nexora\_project` directory.



This was incorrect because the provided baseline script and challenge `data` directory are located in the parent challenge folder.



I identified the path issue from the command-line error and corrected the project instructions.
